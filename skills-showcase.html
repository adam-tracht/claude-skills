Five ways to change how Claude works.

A small cabinet of skills for Claude Code, arranged along one axis: how human or how machine you want the work to feel. One deslops the prose. One talks like a caveman. One convenes a council of subagents. One runs a second brain. One keeps your plans honest.

Type the slash command, or describe the task and Claude reaches for the right one on its own.

/be-a-human /caveman /council /obsidian-vault /plan
/be-a-human Prose

Strips the AI tells out of writing so it reads like a specific person wrote it, not a language model.

It runs a catalog of patterns that give machine writing away: filler openers, copula avoidance, the tapestry-of-vibrant-nuance vocabulary, binary contrasts, passive fragments that hide who did the thing. It cuts them, names the actor, varies the rhythm, and then self-audits for whatever still smells synthetic.

  • cutFiller and AI vocabulary: delve, tapestry, pivotal, testament, underscore. And copula dodges like "serves as."
  • actorPassive voice and subjectless fragments hide who acts. Name the human doing the thing.
  • rhythmMix sentence lengths, trust the reader, never an em dash.
  • scoreRates 1–10 on directness, rhythm, trust, authenticity, density. Below 7 average means revise.

Reaches for it when you say "deslop" or "make it sound human," or any time it's drafting prose meant to pass as genuinely human-authored.

/caveman Comms

Ultra-compressed replies. Roughly 75% fewer tokens, every bit of the technical substance kept.

Speak terse like smart caveman. Drop articles, filler, and pleasantries; keep the exact technical terms, code, and quoted errors. Three intensity levels turn the dial from tight-professional to telegram. The mode persists every response until you call it off.

  • dropArticles, hedging, "happy to help." Fragments fine. Short synonyms: big not extensive.
  • levelslite keeps full sentences, full is classic caveman, ultra abbreviates and uses arrows for causality.
  • safeCode, commits, PRs, and destructive-action warnings snap back to plain English.

Reaches for it when you say "caveman mode," "be brief," or "less tokens." Auto-triggers when efficiency is asked for.

/council Reasoning

Convenes 3–5 isolated subagents, each a distinct mind, then cross-ranks and synthesizes their answers.

The isolation is the whole mechanism. Each councilor answers your question with no memory of the conversation or of each other, so the personas produce real epistemic diversity instead of one model agreeing with itself. Neutral evaluators then rank the anonymized answers, and the Chairman writes the verdict.

  • stage 1Councilors answer independently: Skeptic, Advocate, Pragmatist, plus First-Principles and Minimalist for hard calls.
  • stage 2Three neutral evaluators cross-rank the anonymized answers on accuracy, actionability, and completeness.
  • stage 3The Chairman names the fault line and takes a position instead of averaging.

Reaches for it when you say "council this," or a decision is complex, high-stakes, or genuinely contested.

/obsidian-vault Memory

Reads, writes, and manages notes in the Obsidian "Second Brain" — the canonical source of truth.

The vault holds who Adam is, agent instructions, project context, and durable memory. The skill talks to it through Obsidian's Local REST API so edits index immediately, and falls back to the filesystem when the API is down. It already knows the folder map and where the important files live.

  • apiLocal REST API first (self-signed cert, per-device port), plain filesystem read/write as fallback.
  • mapKnows the vault layout and key files: Adam.md, shared agent rules, memory and writing conventions.
  • linksFiles new notes in the right folder and adds [[wikilinks]] to related notes.

Reaches for it when you mention notes, the vault, or the second brain. Needs a per-device token filled in after install.

/plan Workflow

Scope work in chat, get one recommendation, then write a phased plan doc that survives across sessions.

A planning loop for solo devs who want structure without PR ceremony. It discusses the tradeoffs first and gives one honest recommendation. Nothing hits disk until your two-word go. Then it writes a phased doc to plans/ that you can resume weeks later by asking what's left.

  • discussScope the real problem, surface tradeoffs, one recommendation, then stop and wait for the go.
  • phasedDoc grouped by impact and effort, not a flat list. Irreversible steps sequenced explicitly last.
  • resume"What's left from @plans/x.md" reads status and picks up. Ships flip to ✅ with an evidence note.

Reaches for it when you're scoping work, writing a PRD, or asking what's left from an existing plan.

Install one

Skills live at ~/.claude/skills/<name>/SKILL.md. Claude Code watches that folder, so a skill is live in the next session. No JSON, no CLI.

# grab a single skill mkdir -p ~/.claude/skills/be-a-human curl -o ~/.claude/skills/be-a-human/SKILL.md \ https://raw.githubusercontent.com/adam-tracht/claude-skills/main/be-a-human/skills/be-a-human/SKILL.md # or register the whole marketplace claude plugins marketplace add adam-tracht/claude-skills claude plugins install council@adam-tracht-skills

One note on obsidian-vault: the REST API token is generated per device, so the version in the repo ships with a placeholder. Open the SKILL.md after install and drop in your real token from Obsidian's Local REST API settings.
